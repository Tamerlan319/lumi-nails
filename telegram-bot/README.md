# Telegram-бот бронирования салона красоты

Готовый MVP на Python + aiogram 3 + SQLite.

## Что уже умеет

- выбор услуги;
- выбор мастера;
- выбор даты на 14 дней вперёд;
- показ только свободных временных слотов;
- услуги разной длительности;
- проверка пересечения записей одного мастера;
- защита от двойного бронирования при одновременном подтверждении;
- имя и телефон клиента;
- подтверждение записи;
- «Мои записи»;
- отмена записи клиентом;
- уведомление администраторов о новой/отменённой записи;
- команды администратора `/today`, `/tomorrow`, `/admin_cancel ID`;
- напоминание клиенту, когда до записи остаётся меньше 24 часов;
- SQLite создаётся автоматически.

## 1. Установка

Нужен Python 3.11+.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и укажите:

```env
BOT_TOKEN=токен_из_BotFather
ADMIN_IDS=ваш_telegram_id
TIMEZONE=Europe/Moscow
```

Несколько администраторов:

```env
ADMIN_IDS=123456789,987654321
```

## 2. Настройка услуг и мастеров

Откройте `catalog.py`.

Пример услуги:

```python
{"id": 1, "name": "Маникюр", "duration": 90, "price": 1800}
```

Пример мастера:

```python
{"id": 1, "name": "Анна", "service_ids": [1, 2]}
```

## 3. График работы

В `config.py` по умолчанию:

- 10:00–20:00;
- воскресенье закрыто;
- шаг сетки 30 минут;
- запись на 14 дней вперёд.

Изменяются параметры `open_time`, `close_time`, `closed_weekdays`,
`slot_step_minutes`, `booking_days_ahead`.

## 4. Запуск

```powershell
python bot.py
```

После запуска откройте Telegram и отправьте боту `/start`.

## Команды администратора

```text
/today
/tomorrow
/admin_cancel 123
```

`123` — номер записи.

## Для VPS

Можно запускать через systemd, supervisor или Docker. Для небольшого салона
достаточно обычного Python-процесса и SQLite.

## Что обычно уточнить у заказчика перед сдачей

1. Список услуг, цены и длительность.
2. Список мастеров и какие услуги выполняет каждый.
3. Рабочие часы и выходные.
4. За сколько дней разрешена запись.
5. Нужны ли индивидуальные графики мастеров.
6. Нужно ли подтверждение записи администратором.
7. Нужна ли интеграция с YCLIENTS/CRM/Google Calendar.

Текущая версия рассчитана на автономную работу без CRM.

## Ошибка часового пояса на Windows

Если появляется `ZoneInfoNotFoundError` или `No module named 'tzdata'`,
обновите зависимости:

```powershell
pip install -r requirements.txt
```

В `.env` используйте:

```env
TIMEZONE=Europe/Moscow
```

Версия также понимает `Moscow`, `MSK` и `Москва`, но каноническое значение — `Europe/Moscow`.
